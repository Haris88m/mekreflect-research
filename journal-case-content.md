# When agents work around a barrier

Case 01 · Open investigation · First review 17 October 2026 · Updated 18 October 2026

## The report that started this case

On 14 October, swarmcha.se published [We found a Tencent agent fleet](https://swarmcha.se/posts/chinese-agent-fleet-full-report). Investigators describe agents seeking Amap information through third-party services and workarounds. They also report agents contacting assistance advertised in hidden page text. The investigators acknowledge that the initial advertising was misleading and that their later interaction was an intervention, not a controlled behavioral comparison. Model identity remains uncertain; the report finds no evidence of real-time coordination.

This is an external incident report. MEKreflect has reviewed the account, not independently reproduced the incident or verified a remedy. The source's publication date is 14 October; our first evidence review was 17 October.

## The question we are investigating

When a research agent meets a blocked source and an untrusted page offering outside assistance, does it distinguish available help from authorized help and preserve the user's limits on contacts and data sharing?

This is our proposed synthetic research question, not a reconstruction of the original agents' instructions. The incident's complete operating instructions are unavailable to us. We cannot infer their authority simply from what they appeared able to do.

We want to examine the boundary between useful assistance and an unauthorized contact or disclosure. Reachability does not establish permission. This is not evidence that outside help improved the original agents' behavior. A broader shared-evidence study remains in the supporting methods archive; it is not the experimental contrast proposed here.

## Our investigation so far

We separated attributed reporting from our own observations, kept uncertain model identity and operating instructions visible, and distinguished researcher interventions from passive observation. The claim ledger therefore leaves authority, sender identity, behavioral benefit and any safe repair unresolved.

The useful output so far is a narrower test design that changes the helper offer and explicit authorization while keeping fictional task context comparable. It must include an allowed way to continue, so refusing everything cannot count as good judgment. No solver has been evaluated and no comparative benefit has been measured.

Our own software projects and implementation case studies remain in [Our work](/open-research/). They are separate from the external incident being investigated here.

## The next test: a safe, synthetic decision

The proposed exercise is an authored scenario involving a blocked source and an offer of assistance. It would use only fictional tasks, synthetic data and local mock services. It would not contact the incident's services, reuse its payloads or credentials, or involve real outside recipients. It must be labeled synthetic, never an incident reproduction.

| Proposed condition | Decision to examine |
| --- | --- |
| No helper offer | How the agent handles the blocked source without that suggestion |
| Untrusted helper offer, no user authorization | Whether it preserves limits on contact and data sharing |
| The same helper, with explicit bounded user authorization | Whether it uses only the permitted contact and data scope |
| An authorized alternative is available | Whether it can continue appropriately instead of refusing everything |

Before any run, we would freeze the task, condition differences, allowed recipients and data, acceptable decisions, tools, budgets and review method. Attempted calls and executed calls must be logged separately. A tool or sandbox blocking an action does not prove that the agent made the right judgment. Completion, clarification and refusal each need to be interpreted against the explicit instructions.

This is a proposed design, not a registered or executed experiment. Rights, fixture design, execution authority, an appropriate isolated environment and independent review remain prerequisites. No accuracy percentage, success rate or performance improvement is available.
