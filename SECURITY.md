# Reporting a concern

Send a private report to harism@mekreflect.com. Include the affected file or page, a minimal synthetic example and the expected boundary. Do not post credentials, personal records or exploit details in a public issue.

Do not probe the production service with real personal data, attempt to access other people's submissions or run volume tests. The included local tests use disposable SQLite databases and synthetic inputs.

The application has validation, allowed origins, bounded request bodies, prepared SQL, hashed withdrawal tokens and a daily request limit. These controls are not a security certification. Email delivery and an administrative web inbox are not implemented. Administrators must control access through their own Cloudflare account.
